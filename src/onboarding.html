Før du giver tilladelse

Udvidelsen gør én ting: henter billeder fra links, du selv indsætter, så du kan bygge fits nemmere.

✓ Henter kun billeder fra de links, du selv indsætter
✓ Henter, gemmer eller ændrer aldrig personlige data
✓ Ingen tracking, ingen annoncer — og vi gemmer ingen cookies
✓ Open source — koden kan auditeres på GitHub
  1. Åbn Safari → Indstillinger → Udvidelser
  2. Vælg dripd i listen til venstre
  3. Sæt dripd.dk til Tillad altid
Du kan slå udvidelsen fra eller fjerne den når som helst i Chrome.
